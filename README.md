# Слопчик

Один процесс: бот в Telegram и сообщения сообщества ВКонтакте. Нейросети, картинки, голос и поиск общие.

Telegram запускается всегда. ВК включается, только если в окружении задан `VK_GROUP_TOKEN`.

## ВК

1. Сообщество → Управление → Сообщения → включить сообщения сообщества и возможности ботов.
2. Управление → Работа с API → Создать ключ. Права: сообщения сообщества, фотографии, документы.
3. Там же → Long Poll API → включить. Версия API `5.199`. Событие: входящее сообщение (`message_new`).
4. Render → Environment → добавить `VK_GROUP_TOKEN` (сам ключ, без кавычек). Сохранить и дождаться деплоя.
5. Написать сообществу в личные сообщения с обычного аккаунта.

`VK_GROUP_ID` нужен только если бот сам не определил сообщество. В логах должна появиться строка `vk: сообщество …`.

Команды те же: `/help`, `/prompt`, `/image`, `/reset`, `/status`. В беседе бот отвечает, если его назвали «Слопчик» или ответили на его сообщение.
